## 🚀 Featured Projects

### 1. TaskFlow — Distributed Job Processing System

A distributed asynchronous job-processing system designed for reliability, scalability, and fault tolerance.

**Key highlights**
- ⚙️ Built asynchronous job processing using **BullMQ and Redis**.
- 🔄 Implemented retries, rate limiting, backpressure, and delayed scheduling.
- 🛡️ Added health monitoring and stalled-job recovery for resilient worker execution.
- 📈 Benchmarked worker scaling, reducing simulated job-processing time from **11.21 minutes to 1.17 minutes**.
- 🚀 Achieved a reported throughput of **325.52 job submissions/sec** under the benchmark workload.

**Tech:** Node.js · Express.js · PostgreSQL · Prisma · Redis · BullMQ · React · Tailwind CSS

### 2. CodeCollab — Real-Time Collaborative Code Editor

A collaborative coding platform that enables multiple users to edit code together with live synchronization and isolated code execution.

**Key highlights**
- 👨‍💻 Built a real-time collaborative editor with **Monaco Editor** and support for 11+ programming languages.
- ⚡ Implemented multi-user synchronization using **Socket.IO and Yjs CRDTs**.
- 🔐 Added JWT-secured role-based workspaces and persistent backend storage.
- 🧪 Integrated a sandboxed Judge0 execution pipeline with live HTML/CSS/JS previews.
- 
**Tech:** React · Node.js · Express.js · MongoDB · Socket.IO · Yjs · JWT · Judge0 · Tailwind CSS

### 3. MockMate — AI-Powered Interview Platform

An AI-powered interview preparation platform offering personalized technical and voice-interview experiences.

**Key highlights**
- 🤖 Generates interview questions for 10+ roles and supports six interviewer personalities.
- 🎙️ Provides text and voice interview modes with automated evaluation and performance reports.
- 🧠 Integrates the Groq API for question generation and response analysis.
- 🔊 Uses the Vapi API for conversational voice interviews.
- 🔒 Implements JWT authentication, HTTP-only cookies, bcrypt, and API rate limiting.

**Tech:** React · Node.js · Express.js · MongoDB · Groq API · Vapi · JWT · Tailwind CSS
